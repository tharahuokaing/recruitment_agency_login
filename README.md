A responsive, modern, and production-ready **Login Authentication Portal** designed for **Huokaing Thara Recruitment Agency (ភ្នាក់ងារជ្រើសរើសពលករ ហួកាំងថារ៉ា)**. Features a clean dark/gold UI, modal popup overlay, input validation, password toggle, and instant bilingual toggling (Khmer 🇰🇭 / English 🇬🇧).

## 🚀 Live Demo

🔗 **Live Deployment:** [Huokaing Thara Login Portal](https://tharahuokaing.github.io/recruitment_agency_login/)

## ✨ Features

- **🌐 Dual Language Support (Khmer & English):** Instant language switching using HTML `data-km` and `data-en` attributes.
- **🔒 Interactive Popup Modal:** Glassmorphism overlay modal triggered via header/hero navigation buttons.
- **👁️ Password Visibility Toggle:** Easily reveal or mask passwords with an interactive eye icon.
- **📱 Fully Responsive Design:** Optimized for mobile phones, tablets, and desktop displays.
- **⚡ Custom Form Validation:** Dynamic feedback for missing input fields and credentials.
- **🎨 Custom Agency Aesthetics:** Styled with the agency's signature dark navy (`#0a0e1a`) and gold (`#d4af37`) palette using standard web typography (*Kantumruy Pro* & *Inter*).
